# 首版在现有 AnyDev 独立部署并配置单一模型入口

首版部署在现有 AnyDev 的独立目录中，与旧 Agent 分开运行；任务使用宿主构建环境和独立 worktree，不要求每任务容器。应用与 Phoenix 服务本身是否容器化，在部署方案中另定。真实消息接入需要明确切换，避免两个系统重复处理同一告警。默认 4 个并发能否被实际机器承载，需要后续核实资源，不视为已有容量保证。

首版使用一个可配置的主模型入口，支持用户填写 API Key 和 endpoint，不增加按任务分配模型或自动切换服务商的规则。具体模型标识与 API 协议在接入时确定，不由 endpoint 地址猜测；本阶段不收集密钥。

查询能力优先复用现有可独立运行的 CLI、API 或 MCP 工具，通过薄适配接入 Pi；拆除对旧宿主身份、会话和调度的依赖。原有技能中的业务知识、排查步骤和仓库约定保留，依赖旧宿主的部分改写；审批、倒计时、重试和完成条件由应用管理，不仅靠技能文本约束。
