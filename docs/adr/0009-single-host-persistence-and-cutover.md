# 单机持久化，按群切换新任务

首版使用 SQLite 持久保存任务、方案、Owner 指令、倒计时和操作记录；工作区与大型证据单独保存为文件，Pi 会话另外保存。Phoenix 的 7 天保留规则仅作用于追踪数据。首版安排备份和恢复，具体周期与恢复步骤在部署方案中确定；确需多台调度节点时再迁移数据库。

先通过测试群完成真实闭环，再按群切换：已切换群的新任务由新系统接收，旧系统完成存量任务，首版不迁移执行到一半的旧系统会话。切换时避免新旧系统重复接收同一任务。

验收覆盖重复消息去重、延期与暂停、超时执行、进程中断恢复、并发任务隔离，以及 MR 当前代码版本检查通过后完成。测试群闭环与这些场景通过前，不将新系统视为已经验收上线。

首次交付必须覆盖完整链路：企微接入、调查、Owner 等待流程、并发执行、修复、MR 审查与必需检查、只读看板和 Phoenix。只读调查可以作为开发中间里程碑，不能代替首版最终验收。
